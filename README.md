# 100 Days of Code: The Complete Python Pro Bootcamp

My work from the Python Pro Bootcamp, a project-based course that teaches Python by building one project a day for 100 days.

## About the bootcamp

The bootcamp starts from zero programming experience and builds up to professional-level Python. The idea is simple: code for about an hour a day, and finish each day with a working project. By the end there are 100 projects, which doubles as a portfolio.

The projects get steadily more ambitious. Early days cover the basics through small programs and games. Later days move on to larger builds, including:

- Games and graphical programs
- Desktop apps with a graphical interface
- Automation and bots
- Web scraping
- Web development, including building websites and working with APIs
- Data science and data visualisation

For the full day-by-day syllabus, see the course page linked at the bottom.

## What the course covers

The bootcamp is split into stages, and each day builds on the one before.

**Beginner**
- Python fundamentals: variables, data types, and input and output
- Control flow: conditionals and loops
- Functions, including functions that return values
- Lists, dictionaries and other data structures
- Small projects and games to practise each idea

**Intermediate**
- Object-oriented programming, using classes and objects
- Graphical programs and games, such as Snake
- Working with files and handling errors
- Using external libraries and APIs
- Desktop apps with a graphical interface

**Later stages**
- Web scraping and automation
- Web development, including building websites
- Data science and data visualisation
- Larger projects that bring the earlier skills together

For the full day-by-day syllabus, see the [course page](https://www.udemy.com/course/100-days-of-code/).

## Beyond the course

I have gone a little further than the course in two ways:

- **Testing with pytest.** The course does not cover automated testing, so I added `pytest` tests of my own to check that my code behaves as expected.
- **My own features.** In some projects I changed or extended the code to add features I wanted, which are not part of the course version.

## Running the tests

Install pytest, then run it from the root of the project:

```
pip install pytest
pytest
```
